# ⚡ Neon Physics Playground

A fully interactive 3D physics sandbox built with Three.js and Cannon.js, featuring a stunning neon cyberpunk aesthetic. This project combines realistic physics simulation with professional 3D editing tools, allowing users to spawn, manipulate, and explode boxes in real-time.

## ✨ Features

- **Real-time Physics Simulation** – Gravity, collisions, stacking, and realistic object interactions powered by Cannon.js
- **Professional 3D Controls** – Move, rotate, and scale boxes using TransformControls (similar to Blender/Unity)
- **Instant Box Selection** – Click any box to select it; TransformControls automatically attach
- **Explosion System** – Realistic explosions with fragments, particle bursts, and flash effects
- **Custom Texture Upload** – Upload PNG, JPG, WEBP images as textures on any selected box
- **Neon Cyberpunk Theme** – Glowing edges, glassmorphism UI, dark background with neon accents
- **Mobile Friendly** – Full touch support with responsive design for phones and tablets
- **Professional Loading Screen** – Skeleton loading UI with progress bar and status messages
- **Performance Optimized** – Smooth 60fps rendering with optimized physics and graphics

## 🛠️ Technologies

- **Three.js** – 3D rendering engine
- **Cannon.js** – Physics engine (gravity, collisions, rigid bodies)
- **TransformControls** – Object manipulation (move/rotate/scale)
- **OrbitControls** – Camera controls (pan/zoom/rotate)
- **Vanilla JavaScript** – ES6 modules, async/await
- **CSS3** – Glassmorphism, animations, responsive design
